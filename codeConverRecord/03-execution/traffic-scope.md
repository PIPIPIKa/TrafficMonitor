# 内网和公网历史流量

在历史流量窗口底部选择“全部”“内网”或“公网”。列表中的日、周、月、季、年统计以及日历、月合计和提示同步切换。

“全部”沿用所选网卡的收发总量。两个分类独立记录实际观察到的帧字节。使用电脑已安装的 Npcap，无需混杂模式。程序只短暂读取报头并累计字节数。历史文件只保存每日四项计数。安装前的历史、没有采集权限或驱动缺失时的流量，以及抓包丢失的流量只体现在“全部”。分类合计和 Windows 接口计数可能存在差异。

内网包括直接连接的子网、私网 IPv4、共享地址空间、IPv6 ULA 和链路本地地址，以及链路层广播、组播和 ARP。其余可识别的单播 IP 对端计入公网。按物理接口观察 VPN 的外层流量。监控“全部连接”时，分类采集只选择物理网卡，避免同时累计隧道和承载它的网卡。经公司路由器访问的非直连公有地址按公网统计；本机不能判断运营商的实际计费。

需要 Npcap 的以太网数据链路支持。分类不可用时，可在分类视图底部看到提示。首次使用请在退出旧版后启动新版，沿用原数据目录即可保留历史。旧版本保存历史时不会保留新增的分类字段。
